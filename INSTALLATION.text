MHD AI — GUIDE D'INSTALLATION

====================================

1. FICHIERS NECESSAIRES
   ====================================

Vérifie que ton dépôt GitHub contient les fichiers suivants :

index.html
style.css
manifest.webmanifest
sw.js
icon-192.png
icon-512.png

Attention : les noms doivent correspondre exactement à ceux utilisés dans ton code.

====================================
2. PUBLICATION SUR GITHUB PAGES

1. Ouvre ton dépôt GitHub.
2. Va dans Settings.
3. Clique sur Pages.
4. Choisis Deploy from a branch.
5. Sélectionne la branche main.
6. Choisis le dossier /(root).
7. Clique sur Save.
8. Attends la publication de ton site.

====================================
3. INSTALLATION SUR ANDROID

1. Ouvre l'adresse HTTPS de MHD AI dans Google Chrome.
2. Attends que la page se charge.
3. Appuie sur les trois points en haut à droite.
4. Sélectionne Installer l'application ou Ajouter à l'écran d'accueil.
5. Confirme l'installation.

====================================
4. RESOLUTION DES PROBLEMES

Si l'installation échoue :

- Vérifie que ton site utilise HTTPS.
- Vérifie que manifest.webmanifest existe.
- Vérifie que les icônes sont présentes.
- Vérifie que le service worker est correctement configuré.
- Recharge le site après chaque modification.
- Attends la publication des dernières modifications sur GitHub Pages.

====================================
5. INFORMATIONS IMPORTANTES

Un fichier ZIP extrait ne s'installe pas directement comme une application Android.

MHD AI doit être publiée comme une PWA (application web progressive).

Ce fichier est un guide d'installation. Il ne transforme pas automatiquement ton application en APK Android.

====================================
FIN DU GUIDE
